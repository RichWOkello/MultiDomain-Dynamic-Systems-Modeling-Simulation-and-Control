# Project Website

Static, GitHub Pages-ready website for **Multi-Domain Dynamic Systems Modeling, Simulation and Control**.

## Files
- `index.html`
- `styles.css`
- `app.js`

## Run locally
Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

## GitHub Pages
Place these files in the repository root or a `/docs` folder, then enable GitHub Pages in the repository settings.
